# Dota 2 Binary Trees Visualisation

Визуализатор бинарных деревьев в кастомке Dota 2. Вершины — виспы, рёбра — Tether. Можно добавлять и искать ключи командами, а удалять — в том числе хуком Пуджа или массовой способностью.

Сейчас реализован **обычный BST на C++17**. Красно-чёрное дерево, splay и декартово дерево пока не реализованы.

## Как работает

- **C++** хранит дерево, выполняет вставку, поиск и удаление, рассчитывает глубины и порядок вершин.
- **Lua** создаёт юнитов и частицы, обрабатывает чат и смерти вершин.
- **Python** служит транспортным мостом для нативной Linux-версии Dota, где `CreateHTTPRequestScriptVM` может возвращать `nil`. Алгоритмов деревьев в Python нет.

При доступном HTTP API Lua обращается прямо к C++. Иначе команда записывается в `console.log`, мост отправляет её локальному HTTP-серверу и записывает ответ в KeyValues-файл, который читает Lua. Передаётся только информация, а не исполняемый код.

Смерти за 80 мс объединяются в пакет: один `POST /delete_many` и один снимок дерева. Рёбра погибших вершин исчезают сразу; неизменившиеся Tether переиспользуются.

## Запуск на Linux

Проверено на Arch Linux с нативной Dota 2. Для текущего прототипа не нужны Proton или Workshop Tools: используется поставляемая с игрой карта `test_basic`.

Нужны Dota 2, Python 3 и компилятор с поддержкой C++17. Для Lua-тестов нужен `lua`.

```bash
git clone https://github.com/BlackDiamond2108/dota2_binary_trees_visualisation.git
cd dota2_binary_trees_visualisation
python3 install_addon.py
./start.sh
```

Оставьте терминал с сервером и мостом открытым. Сервер слушает только `127.0.0.1:8765`; второй экземпляр на том же порту запускать не нужно.

Если Steam-библиотека расположена в другом месте:

```bash
export DOTA_GAME_DIR="/путь/к/dota 2 beta/game"
python3 install_addon.py --dota "$DOTA_GAME_DIR"
./start.sh
```

Добавьте в параметры запуска Dota **`-console -condebug`**. Лог консоли необходим файловому мосту. В консоли игры выполните:

```text
dota_launch_custom_game tree_visualizer test_basic
```

Зайдите за Radiant и напишите `-demo` в чат. После изменения Lua-файлов повторите установку аддона и перезапустите карту. Дерево живёт в памяти сервера; перезапуск C++ сбрасывает его.

## Команды в игровом чате

| Команда | Действие |
| --- | --- |
| `-demo` | Дерево из 7 вершин |
| `-big_demo` | Дерево из 75 вершин |
| `-big_demo 200` | Дерево из указанного числа вершин |
| `-insert 42` | Вставить ключ; дубликаты игнорируются |
| `-find 42` | Подсветить путь поиска |
| `-delete 42` | Удалить ключ |
| `-clear` | Очистить дерево |
| `-tree` | Синхронизировать дерево; повторить неудавшиеся удаления |
| `-gold 5000` | Добавить золото; без числа — 10 000 |
| `-lvlup 10` | Добавить уровни до максимума 30; без числа — один |
| `-change_hero axe` | Сменить героя, сохранив золото, опыт и положение |
| `-refresh` | Восстановить здоровье и ману, сбросить перезарядки и заряды |
| `-clean` | Повторить очистку игровых деревьев, рун и отдельных декораций |
| `-help` | Показать команды |

Ключи — знаковые 32-битные целые числа. `big_demo` принимает положительное количество узлов в этом диапазоне и вставляет медианные ключи первыми: разветвлённая демонстрация получается без алгоритма самобалансировки.

У вершин 1 HP, они принадлежат Dire. Их смерть удаляет ключ из C++ BST. Пудж получает хук четвёртого уровня с восстановлением маны и перезарядки. В песочнице включён `dota_easybuy`: покупки доступны везде, включая секретную лавку, и бесплатны.

## Проверки

```bash
g++ -std=c++17 -Wall -Wextra -Werror -O2 test.cpp -o bst-test
./bst-test
lua test_view.lua
```

C++ проверяется сравнением 10 000 случайных операций со `std::set`, длинной цепочкой и большим демонстрационным деревом. Lua-тест проверяет объединение 300 смертей, порядок команд, повторное использование рёбер и повтор неудавшегося удаления.

## Файлы

- `bst.hpp` — BST, обходы, раскладка и сериализация.
- `server.cpp` — локальный HTTP API, включая пакетное удаление.
- `bridge.py` — мост между логом игры и HTTP API.
- `addon/` — исходники кастомки.
- `install_addon.py` — установка файлов кастомки в Dota.
- `start.sh` — сборка и запуск сервера с мостом.

## Текущие ограничения

Искусственный лимит на число вершин снят, но все видимые вершины пока являются отдельными юнитами: производительность Dota ограничивает практический размер сцены. Проверка передачи тысяч узлов не означает проверку их FPS в игре. Пошаговой анимации алгоритмов пока нет.

`test_basic` — готовая карта Valve. Скрипт убирает игровые деревья, руны и отдельные объекты; выступы и декорации, запечённые в геометрию, требуют пересборки карты. Бинарные файлы карты и ресурсы Valve в репозиторий не включены.
